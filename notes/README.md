# Revision notebooks

Interactive revision notes for CCEA Digital Technology, one notebook per unit. Each page is headed by a specification point and has notes, an interactive diagram, quick checks, past-paper questions with tips, videos and glossary terms. Every page has a Learn and practise strip that opens its hub lesson inside the page (video, podcast, slides, fact file, quiz, worksheet, activities), and the first page of each chapter has the topic test, practice paper and topic PowerPoint.

## Adding your topic PowerPoints

Put one PowerPoint per topic in `notes/slides/`, named by topic id, for example `notes/slides/T1.pptx`. The full list of file names is in `slides/README.md`. The first page of each chapter then shows "Topic slides" with View and Download buttons.

On GitHub Pages, the hub content (video, podcast, slides, fact file, quiz, worksheet, activities, topic tests and practice papers) opens inside each page from `../hub.html?embed=1` (GCSE) and `../gce/hub.html?embed=1` (GCE). The front door is `../index.html`.
