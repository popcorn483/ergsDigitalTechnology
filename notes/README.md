# Revision notebooks

Interactive revision notes for CCEA Digital Technology, one notebook per unit. Each page is headed by a specification point and has notes, an interactive diagram, quick checks, past-paper questions with tips, videos and glossary terms. Every page links to its lesson in the hub (video, podcast, slides, worksheet, quiz, activities), and each chapter links to its topic test and practice paper.

The A2 2 coursework guide will be added here when it is finished.

## Adding your topic PowerPoints

Put one PowerPoint per topic in `notes/slides/`, named by topic id, for example `notes/slides/T1.pptx`. The full list of file names is in `slides/README.md`. The first page of each chapter then shows "Topic slides" with View and Download buttons.

On GitHub Pages, links to the hub go to `../index.html` (GCSE) and `../gce/index.html` (GCE) in this repo.
