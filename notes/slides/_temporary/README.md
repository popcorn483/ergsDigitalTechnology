# Temporary topic PowerPoints

These are stand-in PowerPoints, one per hub topic (`T1.pptx` is GCSE Unit 1 topic 1, `G12.pptx` is GCE topic 12, and so on),
exported from the hub's whole-topic PowerPoint. The front page and the workbooks show one, with an amber **Temporary**
badge, only when the chapter's own folder has no PowerPoint, PDF or link in it.

Upload your own PowerPoint to the chapter's folder as usual and it replaces the temporary one automatically. You don't
need to delete anything here, and nothing in this folder is ever treated as your upload.
