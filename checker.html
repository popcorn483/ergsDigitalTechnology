Paper checker

Hold your phone or webcam over a pupil’s answer to a CCEA past-paper question. It finds the question, marks the handwriting against the official mark scheme, highlights the creditworthy parts and suggests the mark.

Suggestions only: you decide the final mark. Photos go to Anthropic’s Claude to be marked and aren’t kept on this site; keep pupils’ names out of the frame.

    Settings

    The checker uses Claude (Anthropic) to read handwriting and apply the mark scheme. Paste an API key from console.anthropic.com › API keys. It’s stored only in this browser on this device, never on the website. Each check costs about 1–3p.

    Pupils’ work is sent to Anthropic’s API to be marked. Anthropic doesn’t train on API data. Keep names and candidate numbers out of the frame, and check this fits your school’s data protection guidance.
