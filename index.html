Where to upload topic PowerPoints

Put a PowerPoint (or PDF) with any file name in the topic’s folder in the GitHub repo. Too big for GitHub (over 25 MB)? Put a OneDrive, SharePoint or Google Drive share link in a link.txt file in the folder instead. It appears on this page and in the workbook a minute or two later.
