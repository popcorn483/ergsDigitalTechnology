Teacher: adding KS3 resources

Each topic is a folder in the GitHub repo: ks3/Year 8/01 Topic name/. Upload files into it and they appear here a minute or two later (a GitHub Action lists them and makes a PDF copy of PowerPoint, Word and Excel files so pupils can view them in the browser). Name files like 1 - LESSON - Under the Hood.pptx or 3 - WORKSHEET - Binary.docx: the number sets the order and the word sets the type (LESSON, NOTES, WORKSHEET, HOMEWORK, ACTIVITY, PRACTICAL, ASSIGNMENT, HELPSHEET). A new topic is a new numbered folder. Titles, summaries and “What you’ll learn” are in ks3/topics.json. Over 25 MB? Put a OneDrive or Google Drive share link in a .txt file in the folder instead.
