Unit 5Digital Development Practice (controlled assessment tutorials)

Coursework: taught as a build alongside the theory. Work through the stages in order; the workbook has each task, where it goes and a checklist.

#TopicHub lessonsWeeks
1Getting set up7 workbook sections
  • Tasks 1–5 from the guidance booklet: your OneDrive folder, a correctly formatted Write Up document, the front page, header and footer, contents page and the Design chapter subtitle page.
2Design14 workbook sections
  • Tasks 6–15: introduction, functional and non-functional requirements, target audience, data requirements, objects, wireframes, User Feedback I, final designs, control tables, flowcharts and pseudocode, navigation structure, User Feedback II and submission. Worked examples use the fictional Ballyvaren High School Tuck Shop – your own work must use this year's CCEA scenario.
3Building it in Visual Studio12 workbook sections
  • TASK 16: build your program in C# (Windows Forms, Visual Studio) and record every error you fix. Step-by-step tutorials on the fictional Ballyvaren High School Tuck Shop practice project: forms with user help, classes, lists, navigation, files, validation, calculations, display, searching, sorting and debugging.
4Testing5 workbook sections
  • Tasks 17–19: the Testing chapter subtitle page, the requirements being tested, test cases, a full test table with valid, invalid, null and extreme data, and corrective actions. Examples use the fictional Ballyvaren High School Tuck Shop.
5Evaluation11 workbook sections
  • Tasks 20–24: evaluate every user requirement (met, partially met or not met, with evidence and further developments), reflect on each stage, and write the performance, robustness and personal reflection sections, with paragraph frameworks and sentence starters.
6Before you submit2 workbook sections
  • Extra help that is not a booklet task: frequently asked questions and the full checklist from the guidance booklet, with final checks before you upload your Word and PDF copies.
Total

A2 2Building in Access and VBA (tutorials)

Coursework: taught as a build alongside the theory. Work through the stages in order; the workbook has each task, where it goes and a checklist; the Access tutorial library (chapters 18 to 24) is for pupils to dip into as they build.

#TopicHub lessonsWeeks
1Choose your project11 workbook sections
  • Pick a project with a real user, real data and 5–7 tables, browse eight shop, booking and job ideas with full project cards, and turn your choice into numbered requirements.
2Design your database11 workbook sections
  • Design QuickFix Phone Repairs from its paper job card: normalise to 3NF, draw the ER diagram, write the data dictionary and validation, and plan the forms, queries, reports, test data, names and menu before you build anything.
3Getting started with Access5 workbook sections

  • AD04 Development: building and evidencing the database application
9VBA task tutorials11 workbook sections
  • AD04 Development: building and evidencing the database application
  • AD05 Testing and evaluation against the requirements
10Booking system: tables, relationships and forms9 workbook sections
  • Start the Mournview Dance & Music Academy booking system: six tables with validation and lookups, five relationships, sample data, session queries with spaces left, and the customer, activity, session and booking forms with a menu.
11Booking system: the booking logic in VBA10 workbook sections
  • Write the Mournview booking rules in VBA: spaces left and capacity, the minimum-age check, instructor and customer double-booking, cost and balance, cancelling with refunds, a session register, a booking search and a reused login.
12Booking system: reports, menu and finishing touches6 workbook sections
  • Finish Mournview: a daily register grouped by session, a one-booking confirmation saved as PDF, income by activity, unpaid balances, the start-up menu with the Navigation Pane hidden, and a full test plan for the booking rules.
13Your coursework: setting up the write-up4 workbook sections
  • Tasks 1–3 of your teacher's Year 14 guidance: create the write-up file in the right place, give it a title page, header and footer, and set up heading styles and an automatic contents page before you start writing.
14Your coursework: the Analysis chapter12 workbook sections
  • Tasks 4–15 of your teacher's guidance: the subtitle page, Introduction, Gantt chart, critical path, constraints, user requirements, hardware and software, data flow diagrams and user feedback.
15Your coursework: the Design chapter10 workbook sections
  • Tasks 16–24 of your teacher's guidance: the subtitle page, structure diagrams, ER diagrams, normalisation, data dictionaries, interface, query, macro and report designs, then build the database you designed in Access.
16Your coursework: the Testing and Evaluation chapter11 workbook sections
  • Tasks 25–34 of your teacher's guidance: the subtitle page, testing strategy, unit, integration, system and acceptance testing, then changeover, staff training, evaluation and personal performance.
17Your coursework: the User Guide, Appendix and Bibliography9 workbook sections
  • Tasks 35–41 of your teacher's guidance: the user guide subtitle page, introduction, system requirements, installation, using the system, troubleshooting and FAQs, then the optional Appendix and Bibliography and the final checks before hand-in.
Total

Weeks = hub lessons × periods per lesson ÷ periods a week, rounded to the nearest half week (a workbook-only topic counts one lesson per two workbook sections). Coursework units have no weeks: they run to your own internal deadlines. A rough guide only: adjust for your own calendar. AS 1 and AS 2 run side by side, so share the A level periods between them.
